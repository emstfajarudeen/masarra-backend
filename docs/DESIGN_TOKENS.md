## Admin UI rule

- Use the Masarra variables above for admin UI screens.
- Do not introduce a separate admin color system unless explicitly approved.
- Admin can be more functional/dense than public UI, but must keep the same purple/yellow/white visual identity.
- Arabic-first RTL layouts must use the same palette and spacing rhythm as the public UI.
